Web fonts that you see in the Web Font Manager can be used in any of the mailing tools (Events mailing, Contacts Mailing & Data Privacy mailing) but only in Drag and Drop mode. Select a web font in your email Start by Creating a new mailing or Editing an existing mailing Ensure you are in Drag & Drop mode by going to the Choose Template tab and clicking the Drag & Drop button Go to the Design tab Add a text element or select an existing text element. Highlight the text In the toolbar adjacent to the text, open the font dropdown.
