Setting up a timeslots event To configure an appointment-based event with timeslots, open your event's Create/Edit page and navigate to the Time & Capacity section: Once there, click the + button to add as many slots as you need: You can also bulk-create slots by clicking the ⋮ button, setting the event's start and end time, then choosing the duration of each slot. This will generate the full series automatically: Set a name and capacity for each slot. Once a slot reaches its capacity, no more invitees can RSVP, keeping attendance controlled automatically.
