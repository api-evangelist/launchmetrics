🗓 released July 23rd ✅ Print multiple location barcodes at once You can now print multiple location barcode labels in a single action in Samples, using a print queue. No more printing labels one location at a time. In Location Editor , a queue option lets you add several locations and print all their barcode labels together in one batch.
