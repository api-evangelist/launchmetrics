# Launchmetrics

> Launchmetrics is the Brand Performance Cloud for the fashion, luxury and beauty industries, formed
> from Fashion GPS and Augure. It publishes a small public REST API reference — the NAP APIs — that
> exposes the publication, media-outlet and audit-log data behind its Discover and Insights products.
> Requests carry an `app_id` issued by Launchmetrics R&D, optionally strengthened with an HMAC-SHA1
> request signature. There is no OpenAPI, no SDK, no MCP server and no self-service sign-up.

> Generated by API Evangelist from the public reference at https://nap.launchmetrics.com/docs on
> 2026-08-17. Launchmetrics does not publish an llms.txt for its API surface; the only llms.txt on the
> estate is the Teamtailor-generated careers file at https://careers.launchmetrics.com/llms.txt.

## APIs

- [Launchmetrics Search API](https://nap.launchmetrics.com/docs/search.html): Lucene-syntax search over the
  indexed publication corpus. `GET|POST /documents` with query, filter, period, sort and offset/limit
  paging; `GET|POST /documents/facets` for faceted aggregations. Base
  `https://nap.launchmetrics.com/search/v1`.
- [Launchmetrics Documents API](https://nap.launchmetrics.com/docs/documents.html): Retrieve publication
  documents by id. `GET /documents/{ids}`, `POST /documents`, `GET /socialMediaSearch?url=`,
  `GET /urlCheck?url=&type=`, `GET /image/{documentId}`. Base
  `https://nap.launchmetrics.com/documents/v1`.
- [Launchmetrics Documents v2 API](https://nap.launchmetrics.com/docs/documentsV2.html): Version 2 of
  document retrieval, running alongside v1. `GET /documents/{ids}`, `POST /documents`. Base
  `https://nap.launchmetrics.com/documents/v2`.
- [Launchmetrics Medias API](https://nap.launchmetrics.com/docs/medias.html): Media outlets rather than
  documents. `GET /medias/{ids}`, `POST /medias`, `GET /medias/search`, `GET /medias/print/search`.
  Base `https://nap.launchmetrics.com/medias/v1`.
- [Launchmetrics Auditlogs API](https://nap.launchmetrics.com/docs/auditlogs.html): `GET
  /auditlogs/{team}{group}{id}` with type, limit and sort. Base
  `https://nap.launchmetrics.com/auditLogs/v1`. Note: the documented `/ping` returned 404 on
  2026-08-17, so this service may not be deployed at the published path.

## How to call it

- Authentication: add `app_id` to the query string. For the signed mode add `nonce`, `timestamp` and a
  base64 HMAC-SHA1 `signature` over
  `HTTP_METHOD&url_encoded(request_url)&url_encoded(parameter_string)`, keyed with the app secret.
  Credentials are issued by Launchmetrics R&D; there is no developer console.
- Every response is wrapped: `{status, time, request:{method,path,parameters}, response}` on success,
  and `{status, time, request, error:{code,message}}` on failure. Content type is
  `application/json; charset=utf-8`.
- Paging is offset-based via `start` and `limit`. No cursor, no Link header, no documented page cap.
- Errors are a proprietary code envelope, not RFC 9457. Documented generic codes: `MISSING_PARAMETERS`
  (400) and `INTERNAL_ERROR` (500). Observed live: `APP_ID_NOT_VALID` (401), `MISSING_TENANT` (400),
  `PAGE_NOT_FOUND` (404).
- No idempotency contract, no rate-limit headers and no documented 429 behaviour.
- `GET /ping` and `GET /stats` answer unauthenticated on each service and are the only public health
  signal, since the status page is login-gated.

## Not published

- No OpenAPI, Swagger, GraphQL, AsyncAPI or Protobuf definition is public. A machine-readable OpenAPI
  does exist at `https://api-ter.launchmetrics.com/v1/openapi.json` but it is gated: an anonymous GET
  returns HTTP 401 `APP_ID_NOT_VALID`.
- No first-party SDK on npm, PyPI, RubyGems, Packagist, Maven Central, NuGet or crates.io.
- No CLI, no webhooks, no event/streaming surface, no MCP server, no A2A agent card, no security.txt,
  no public Postman collection, no dated API changelog.
